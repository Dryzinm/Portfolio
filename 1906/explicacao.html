Explicação das Tags Audio e Video

Início Explicação das Tags

Tag Audio

A tag <audio> é utilizada para reproduzir arquivos de áudio em páginas web.

Principais atributos

Atributo Função
controls Exibe os controles de reprodução.
autoplay Inicia automaticamente o áudio.
loop Repete o áudio continuamente.
muted Inicia o áudio sem som.
preload Define como o áudio será carregado.

Exemplo

<audio controls>
   <source src="musica.mp3" type="audio/mpeg">
</audio>

Tag Video

A tag <video> é utilizada para exibir vídeos diretamente no navegador.

Principais atributos

Atributo Função
controls Mostra os controles do vídeo.
autoplay Inicia automaticamente.
loop Repete o vídeo.
muted Inicia sem áudio.
poster Define uma imagem de capa.
width Define a largura do vídeo.
height Define a altura do vídeo.
preload Controla o carregamento inicial.

Exemplo

<video controls width="600">
   <source src="video.mp4" type="video/mp4">
</video>
